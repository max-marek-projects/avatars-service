                    POST
                    /api/v1/avatars
                

                
Upload avatar

                
Multipart request with the file field. Requires the X-User-ID header. Max — 10 MiB.


                

                    

                        
                        
                    

                    

                        
                        
                        

                            
                        

                    

                    
                


                

                    

                    

                

            


            
            

                

                    GET
                    /api/v1/avatars/{avatar_id}
                

                
Get avatar by ID

                
Returns the binary image. The response is shown as a preview plus raw
                    headers.


                

                    

                        
                        
                    

                    

                        Resize and format conversion are not available in this build.
                        The original image is always returned.

                    GET
                    /api/v1/users/{user_id}/avatar
                

                
Active avatar of a user

                
Returns the freshest avatar of the user. If there is none — a placeholder
                    (when configured) or 404.

                    GET
                    /api/v1/avatars/{avatar_id}/metadata
                

                
Avatar metadata

                
JSON with file name, MIME type, size, and the list of thumbnails.


                

                    

                        
                        
                    

                    
                


                

                    

                    

                

            


            
            

                

                    GET
                    /api/v1/users/{user_id}/avatars
                

                
All avatars of a user

                
Every active (non-deleted) avatar of the user with a preview gallery.
                    Delete directly from a card.


                

                    

                        
                        
                    

                    
                


                

                    

                    

                    

                

            


            
            

                

                    DELETE
                    /api/v1/avatars/{avatar_id}
                

                
Delete avatar by ID

                
Soft delete. Verifies that X-User-ID matches the owner, otherwise 403.


                

                    

                        
                        
                    

                    

                        
                        
                    

                    
                


                

                    

                    

                

            


            
            

                

                    DELETE
                    /api/v1/users/{user_id}/avatar
                

                
Delete active avatar

                
Deletes the active avatar of the user whose ID is in the X-User-ID header.


                

                    ⚠️ Make sure the ID below matches the header. Otherwise you may delete someone else's avatar.
